# 7zip-modern-menu

Пункты 7-Zip в новом контекстном меню Windows 11 (без «Показать дополнительные параметры»).
Требуется установленный 7-Zip. Проект независимый, см. [NOTICE.md](NOTICE.md).

## Установка
Скачайте установщик из раздела **Releases** и запустите его.

## Версионирование и выпуск релиза
1. Обновить `VERSION` и добавить раздел `## [X.Y.Z] - дата` в `CHANGELOG.md`.
2. `git commit`, затем `git tag vX.Y.Z && git push --tags`.
3. Actions соберёт файлы и опубликует Release. Версии с дефисом (`-alpha.1`, `-rc.1`) помечаются как pre-release.
