# Правовые заметки

- Проект **не связан** с Игорем Павловым и проектом 7-Zip и не одобрен ими.
  «7-Zip» упоминается только для описания совместимости.
- Репозиторий **не содержит и не распространяет** код, бинарники, иконки и
  ресурсы 7-Zip. Расширение лишь запускает уже установленный у пользователя
  `7zFM.exe` / `7zG.exe` как отдельные процессы (без линковки).
- Код написан с нуля по публичной документации Microsoft (IExplorerCommand,
  sparse packages). Код NanaZip и других проектов не копируется.
- Иконки берутся во время работы из установленного 7-Zip, а не поставляются.
- Лицензия проекта: MIT.
