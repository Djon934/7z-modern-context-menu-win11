# Privacy policy / Политика конфиденциальности

**English**

"Context Menu for 7-Zip (unofficial)" (ModernMenu7z) does not collect, store, or transmit any personal data. The app has no network code and makes no internet connections. It has no analytics, advertising, or accounts.

When you right-click a file or folder, the app passes the selected items to the 7-Zip shell extension that is already installed on your computer and shows the menu that 7-Zip returns. The selection is processed only locally and in memory, and is not saved.

Optional debug log: it is off by default. If you turn it on yourself (registry value `HKCU\Software\ModernMenu7z\Debug`), the app writes a text log to a folder on your own computer. Nothing is sent anywhere, and you can delete the file at any time.

Contact: https://github.com/Djon934/7z-modern-context-menu-win11/issues

**Русский**

«Context Menu for 7-Zip (unofficial)» (ModernMenu7z) не собирает, не хранит и не передаёт никаких персональных данных. В приложении нет сетевого кода, оно не обращается к интернету. В нём нет аналитики, рекламы и учётных записей.

Когда вы нажимаете правой кнопкой на файл или папку, приложение передаёт выбранные объекты в уже установленное на вашем компьютере расширение оболочки 7-Zip и показывает меню, которое вернул 7-Zip. Выбор обрабатывается только локально, в памяти, и не сохраняется.

Необязательный журнал отладки: по умолчанию выключен. Если вы сами включите его (параметр реестра `HKCU\Software\ModernMenu7z\Debug`), приложение запишет текстовый файл в папку на вашем компьютере. Ничего никуда не отправляется, файл можно удалить в любой момент.

Связь: https://github.com/Djon934/7z-modern-context-menu-win11/issues
